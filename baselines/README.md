# Baselines

This directory contains baseline models and tools for comparison.

## P2Rank

Please download P2Rank v2.5.1 from the official repository releases:
https://github.com/rdk/p2rank/releases

Download version 2.5.1 and extract it into this directory.
Expected structure:
```
baselines/p2rank_2.5.1/
```

## PocketMiner (GVP)

Please download PocketMiner from the following repository:
https://github.com/Mickdub/gvp/tree/pocket_pred

Run the following commands in this directory:
```bash
git clone https://github.com/Mickdub/gvp.git
cd gvp
git switch pocket_pred
cd ..
```
Expected structure:
```
baselines/gvp/
```
